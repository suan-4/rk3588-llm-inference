# 01 · 环境准备与部署清单

> 目标：在 RK3588 上跑通 Qwen3.5-0.8B，测出 TTFT / tokens/s / 内存基线
> 最后更新：2026-10-08

---

## 一、主机硬件

| 项目 | 情况 | 结论 |
|---|---|---|
| CPU | i7-12700H / 20 逻辑核心 | 够用，虚拟机给 6 核 |
| 内存 | 16 GB | **瓶颈**，虚拟机最多给 8–10 GB |
| C 盘 | 剩 186 GB | 够用 |
| D 盘 | 剩 32 GB | 太小，虚拟机不放这 |

**内存瓶颈的影响**：自己转换模型时要把 FP16 权重读进内存，4B 需要 12–16 GB，本机不够。
所以先用官方转好的 0.8B，4B 以后租云主机再转。

## 三、装 Ubuntu（手动，约 30 分钟）

1. 打开 VMware → **文件 → 打开** → 选 `Ubuntu-22.04-RKLLM.vmx`
2. 点"开启此虚拟机"，会自动从 ISO 引导
3. 语言任选，安装类型任选
4. **取消勾选"安装 Ubuntu 时下载更新"**（省十几分钟）
5. 磁盘选"清除整个磁盘并安装"（新建空盘，随便清）
6. 用户名用**全小写英文**（如 `he`），密码记牢

### 装完立刻做的 6 件事

```bash
# 1) 换成清华源
sudo sed -i 's|http://.*archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list
sudo sed -i 's|http://security.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list
sudo apt update

# 2) 基础工具
sudo apt install -y build-essential git wget curl unzip python3-pip python3-venv cmake adb

# 3) VMware 共享工具（宿主机与虚拟机互传文件、复制粘贴）
sudo apt install -y open-vm-tools open-vm-tools-desktop

# 4) 确认 Python 版本（应为 3.10.x）
python3 --version

# 5) pip 换清华源
mkdir -p ~/.pip && printf '[global]\nindex-url = https://pypi.tuna.tsinghua.edu.cn/simple\n' > ~/.pip/pip.conf

# 6) 重启使共享工具生效
sudo reboot
```

## 四、装 RKLLM-Toolkit（想自己转模型时才需要）

```bash
# 把 sdk/rknn-llm-release-v1.3.0.zip 从宿主机拷进虚拟机，然后
unzip rknn-llm-release-v1.3.0.zip
cd rknn-llm-release-v1.3.0/rkllm-toolkit

python3 -m venv ~/rkllm-env
source ~/rkllm-env/bin/activate
pip install ./packages/rkllm_toolkit-*-cp310-cp310-linux_x86_64.whl

# 验证
python3 -c "from rkllm.api import RKLLM; print('toolkit ok')"
```

> whl 名字里的 `cp310` 对应 Python 3.10，所以选 Ubuntu 22.04 最省事。
> 只跑现成模型（本次路线 A）可以跳过这一节。

## 五、部署到板子

```bash
# 宿主机（或虚拟机）里推文件
adb push models/RK3588/Qwen3.5-0.8B/*.rkllm /data/
adb push models/RK3588/Qwen3.5-0.8B/*.rknn  /data/
adb push tools/demo_Linux_aarch64 /data/

# 进板子
adb shell
cd /data/demo_Linux_aarch64
export LD_LIBRARY_PATH=./lib:$LD_LIBRARY_PATH
export RKLLM_LOG_LEVEL=1        # 打开性能日志

# 先空跑看参数顺序
./demo
```

完整调用：

```bash
./demo demo.jpg \
  /data/Qwen3.5-0.8B_vision_rk3588.rknn \
  /data/Qwen3.5-0.8B_w8a8_rk3588.rkllm \
  2048 4096 3 \
  "<|vision_start|>" "<|vision_end|>" "<|image_pad|>"
```

## 七、踩坑记录

| 现象 | 原因 | 处理 |
|---|---|---|
| 分享里 1.3.1 是空的 | 上传者只建了文件夹没传文件 | 用 1.3.0 |
| 找不到 Qwen3.5-4B 的预转换模型 | 官方没公开 | 自己转，需要 12–16GB 内存 |
| demo 报 `libomp.so` 找不到 | Linux aarch64 包缺这个库 | 从交叉编译工具链拷到 `tools/demo_Linux_aarch64/lib/`，与 `librkllmrt.so` 同级 |
| 模型加载失败 | NPU 驱动版本和 Runtime 不匹配 | 先查 `/sys/kernel/debug/rknpu/version` 再比对 |
| 下载卡住 / 目录是空的 | 联想云盘客户端会先建空目录，完成才写文件 | 等 `TransMgr` 日志不再变化才算下完 |
